A server is simply a **program** which sends, and receives data from a client.

It is sometimes used to describe a hardware, in this case it refers to a computer hosting a **server**, so a computer whose purpose is to host a particular server.

For instance, a Minecraft server.
A Minecraft server is a **Java** program that gives it's clients (players) all the information that they require to successfully see each other, and interact with each other (player position, player health, player inventory...).
