**Who Is**
[RFC 3912](https://datatracker.ietf.org/doc/html/rfc3912)


>[!quote] A WHOIS server listens on TCP port 43 for requests from WHOIS clients.  The WHOIS client makes a text request to the WHOIS server, then the WHOIS server replies with text content.

Basically, any **WHOIS** server, when nudged will send back to the **WHOIS** client a list of information in **ASCII** concerning it's domain name.

It contains information mainly on how to contact the domain name owner.

A **WHOIS** database actually refers to a **Registrar's DB**, see [[DNS#Registrar]].
>[!quote] The WHOIS database stores information about domains such as the following: **Registration contact information for registrant, admin, and technical contacts**. **Sponsoring registrar**. **Creation, update, and expiration dates**.
