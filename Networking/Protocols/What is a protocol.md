
>[!danger] A Protocol is a set of rules that defines how data is transmitted over a network.

*This is very important DO NOT forget it.*

A protocol is not a piece of code somewhere that all programs must abide to if they want to use it. Rather a protocol is **an abstract set of rules**, that define how information should be formatted to be transmitted. 

A protocol is created for the sake of consistency. This makes it so that we don't have 100 [[HTTP]] all working in their own ways with their personal bits and quirks. We have one [[HTTP]], following one universal set of rules.

You could create your own **protocol** by simply writing on a piece of paper, rules to communicate with you in an imaginary language, such as it's grammar, syntax, and so on.
