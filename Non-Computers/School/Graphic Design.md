
# Composition

Composition is the layout of the different elements on the creative space, they need to work with each other to lead the eye and create a dynamic experience.

## Conformity

Conformity consists of creating stability in the space, using fixed grids.
Anything that breaks this conformity, such as curves, or elements not placed on the grid create a **break**

## Visual Dynamism

Visual dynamism is the way the eye moves around on the image/space. It is directly correlated with the layout of all the different elements.

To direct the eye, **directive lines** are used.
Another way to create visual dynamism, is repetition, patterns. This, like in music creates movement and... *dynamism*

### Different ways to compose
- symmetry
- 3/4th rule
- the diagonal
- Golden Number
- radial grid
- asymmetry
