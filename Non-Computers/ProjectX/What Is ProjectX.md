ProjectX is an app that allows users to "host" or "attend" parties.
A user who hosts a party, creates a post with a **Title**, **Description**, and a few photos if desired. People who desire to attend can request to attend, and the host manually accepts or declines each of them. The host can also choose to set an entrance fee, so that attendees pay.

# Functionalities

## User

- Each user can host, or request to attend a party
- Each user has an account, with a profile picture, pictures and videos of them or their hobbies.
- Each user has a party rating as well as a hosting rating (if they ever have hosted)
	- The party rating allows other users to know how well this person behaves, and acts. **if a user has a low party rating, it could mean that in past parties they were loud/annoying/broke things or so on**
	- The hosting rating allows other users to know how good the parties this user throws are. **if a hosting rating is low, this could mean that the previously thrown parties were lacking in food/beverages, space, general respect or other issues**
- **Each user can be reported or blocked.**

## Party

- Each party has a general area set so that the users know where approximately the party is being thrown
- The real address and details of the location are revealed 2Hours before the party, or some other time if the host choses so.
- The parties can be posted up to 1 year in advance.
- Each user can add or remove friends, and can choose to post their parties either publicly (accessible to anyone with the app) or to their friends only.
- Each user can also choose if the party must be hidden from certain people.
- Each user can see the current guestlist of an upcoming party.
- Each user can choose an attendee limit

## Fees

> [!info] Entrance Fees
> When hosting a party, the host can choose to add an entrance fee. In that case, each user will have to pay to attend. Their payment will be locked 24 hours before the party time, and will be made 12 hours after the party (in case anything notable happened)
>
> This means that a user can pull out or cancel his attendance up to 24 hours before the party, to allow the host to correctly allocate the ressources
> 

Out of the payments made, a percentage will go to me 🥰🥰🥰🥰 yay!


# Security And User Experience

>[!warning] User Verification
>To have the app be as safe as possible **Especially in the eyes of the law** An ID verification **IS REQUIRED**
