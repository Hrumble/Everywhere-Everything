I always thought this was extremely complicated, it's really not.

Signed and Unsigned integers are exactly what they sound like.
a **Signed Integer** is an `int` that has a sign in front, so negative numbers, or positive.
$+32, -42 ...$
an **Unsigned Integer**, does not have a sign in front, so only positive numbers.

**Signed Integers** are marked with the prefix `i` *idk why* so `i16, i32, i64`
**Unsigned Integers** are marked with the prefix `u` so `u16, u32, u64`
