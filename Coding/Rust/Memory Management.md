
There are 3 main different memory management methods to manage the [[Stack and Heap]], each with it's own pros and cons:

|                          | Pros                                                                                | Cons                                                                                                   | E.g.                                            |
| ------------------------ | ----------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------ | ----------------------------------------------- |
| Garbage Collection       | - Error Free<br>- Faster/easier coding                                              | - No control over memory<br>- Slower and unpredictable run time performances<br>- Larger Program sizes | Java, C#, Python, and most high level languages |
| Manual Memory Management | - Control over memory<br>- Faster Runtime<br>- Smaller Program Size                 | - Error Prone<br>- Slower/harder coding                                                                | C, C++, ...                                     |
| Ownership Model          | - Control over memory<br>- Error Free<br>- Faster Runtime<br>- Smaller program size | - Slower/harder coding<br>- learning curve                                                             | Rust, Cyclone...                                |
