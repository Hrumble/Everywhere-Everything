**Run Control Files**

**RC** Files are configuration files that are run when a program starts up. They are written according to the syntax of the specific program they belong to, for instance, the `.bashrc` file is written in `bash` and is executed every time a new bash session is started.

As an example
```bash
echo "Fuck you" >> ~/.bashrc
```
Would make it so that every time the `~` user opens a new bash session, fuck you is written on top.
