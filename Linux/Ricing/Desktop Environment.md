
A **Desktop Environment** (**DE**) is a collection of multiple programs designed to offer the user an all in one graphical interface. 

A **DE** consists primarily of:
1. A [[Window Managers|Window Manager]]
2. Panels/ Taskbars 
	1.  Application Launcher
	2.  System Tray
	3.  Notification Area
3. [[File Managers|File Manager]]
4. [[Terminal Emulators|Terminal Emulator]]
5. Other Desktop Utilities (clocks, wallpapers or other random *useless* stuff)

Let's see some popular Desktop Environments

# Xfce
[official page](https://www.xfce.org)

**Xfce** is a lightweight desktop environment, it's known for it's minimal resource usage compared to other desktop environments.

It follows a **Modular Design** philosophy, which means all of the components making up the desktop environment work independently from each other. A user can easily mix and match without having to worry about the component's compatibility with each other.

>[!info] Xfce has been around for over two decades and has established itself as a stable and reliable desktop environment.

# Plasma
[official page](https://kde.org/plasma-desktop/)

**Plasma** is a pretty big desktop environment with a bunch of software (bloatware btw). It is most often used alongside **KDE** which is nothing more than the group of components plasma uses in it's environment.

They're easily recognizable by their stupid mortal kombat like names : K-terminal, Kmail, Konqueror (web browser), and so on...

>[!info] KDE is highly customizable, allowing users to adjust nearly every aspect of the desktop environment to their preferences. This includes themes, icons, window decorations, desktop widgets (plasmoids), and panel layouts.
