Docker is a tool, that let's you run isolated environment called [[Docker Containers|Containers]].
*similar to a python python Virtual Environments but more powerful*

see the official doc [here](https://docs.docker.com)

## Why do I even need docker ?
*First reason, it's really cool*

Docker let's you compartmentalize your server or even personal computer.
Let's imagine you want to run two different projects, each dependent on multiple libraries and specific versions of specific apps. 
Running both of those projects simultaneously is impossible, but docker let's you do that. Set up 2 [[Docker Containers|Containers]], each with their own apps and versions, and then run both at once!

**Docker** is basically a **Virtual Machine** which takes less of a toll on your PC.
